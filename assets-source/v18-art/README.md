# v0.18 regional artwork record

These project-generated masters follow the workshop direction for Lavendyr Glade and Lavenderway Fields. They are authoring sources; the browser uses derivatives in `dist/assets`.

- `environment-master.png`: source for the regional building, conservatory, well, wagon and birch exports in `lavendyr-v18.png` / `.json`.
- `nature-master.png`: source for the road’s regional nature exports in `lavender-nature-v18.png` / `.json`.
- `creature-master-pending.png` and `creatures-pending.png` / `.json`: retained preview-stage sources for Lavender Imp, Violet Brambleback, Amethyst Wisp and Medusa. The user approved all four designs before their browser integration. The historical `pending` filenames do not indicate an outstanding approval.

The runtime creature sheet is `lavender-creatures.png` / `.json`. Each design has four drawn facings; movement, attack anticipation and recovery use runtime articulation rather than a newly drawn frame-by-frame animation set. Medusa uses her own artwork and does not reuse Briarvault’s minotaur.

The existing free artist-pack credits and their individual terms remain attached to those packs in `dist/credits.html` and the asset provenance files. This regional sheet is a separate project-generated source and should not be attributed to those pack authors. Retain both provenance records when distributing the game.
