# Approved interface masters

These are the original approved Map, Bag and Spellbook images, retained for future artwork work. The browser uses 144-pixel derivatives in `dist/assets/ui`, keeping the same appearance at interface sizes without downloading full-resolution masters. The masters are not part of the playable or offline package.

To reproduce the export in an authoring environment with `@napi-rs/canvas`, run `node tools/prepare-ui-icons.cjs`. The checked-in exports need no image-processing dependency in release CI or on a player's device.
